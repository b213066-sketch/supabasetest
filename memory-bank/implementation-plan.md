# 구현 계획

최종 갱신: 2026-10-28
상태: 계획 작성 완료, 앱 구현 미착수.

## 1. 기반 구성
- [ ] 실제 저장소 루트에 React + TypeScript + Vite 앱과 라우팅을 구성한다.
- [ ] 의존성 버전·잠금 파일, 코드 검사·빌드 명령을 구성한다.
- [ ] 기능별 폴더와 공통 UI 경계를 적용한다.
- [ ] `.env.example`, `.gitignore`, 실행 안내를 작성한다.
- 완료 조건: 한국어 작성·보드 화면 간 이동이 되고 코드 검사 및 프로덕션 빌드가 통과한다.

## 2. Supabase 데이터와 권한
- [ ] 최신 공식 문서와 연결 가능한 프로젝트·환경변수를 확인한다.
- [ ] 익명 인증과 브라우저 세션 재사용을 구성한다.
- [ ] 방명록·댓글 테이블, 외래 키·인덱스·길이 제약을 마이그레이션으로 만든다.
- [ ] 공개 읽기, 본인 ID로 INSERT, UPDATE/DELETE 차단 정책을 구성한다.
- [ ] Storage 공개 이미지 읽기, 본인 경로 업로드와 실패 파일 정리 정책을 구성한다.
- [ ] 필요한 테이블 권한과 Realtime publication을 설정한다.
- [ ] 두 익명 사용자와 미인증 상태로 권한을 검증한다.
- 완료 조건: 허용된 읽기·쓰기가 가능하고 타인 ID 위조, 타인 파일 변경, 방명록·댓글 수정·삭제가 차단된다.

## 3. 방명록 작성
- [ ] 닉네임·메시지·색상과 사진/그림 모드 입력을 구현한다.
- [ ] 사진 미리보기·제거·교체 및 파일 제한을 적용한다.
- [ ] 마우스·터치 그림, 펜 색·굵기·지우개·실행 취소·전체 지우기를 구현한다.
- [ ] 빈 캔버스 검사, 내용 손실 안내, 모바일 스크롤 충돌 방지를 적용한다.
- [ ] 업로드·저장 진행 상태, 제출 중복 방지, 실패 시 입력 유지·재시도를 구현한다.
- [ ] 저장 여부 확인 후 파일 정리와 동일 제출 ID 재사용을 구현한다.
- 완료 조건: 사진 또는 그림 한 장으로 등록하고 보드로 이동하며, 실패 후 내용이 유지되고 재시도로 중복 생성되지 않는다.

## 4. 포스트잇 보드
- [ ] 반응형 포스트잇 카드와 필요한 표시 정보를 구현한다.
- [ ] 최신순 커서 페이지네이션과 더 불러오기를 구현한다.
- [ ] 빈 상태·로딩·오류·재시도와 작성 이동 버튼을 구현한다.
- [ ] 새 방명록 구독, ID 병합, 재연결 재조회, 구독 해제를 구현한다.
- 완료 조건: 다른 브라우저의 새 방명록이 새로고침 없이 한 번만 표시되고 더 불러오기와 함께 동작한다.

## 5. 상세 모달과 실시간 댓글
- [ ] 이미지 확대·전체 메시지·작성자와 댓글 목록을 구현한다.
- [ ] 모바일 레이아웃, 세 가지 닫기 동작, 키보드 포커스·레이블을 구현한다.
- [ ] 댓글 작성·검증·중복 제출 방지·오류 입력 유지를 구현한다.
- [ ] 방명록별 댓글 구독, 오래된 순 정렬, 모달 종료 시 구독 해제를 구현한다.
- [ ] DB 기준 댓글 수 재조회와 보드 반영을 구현한다.
- 완료 조건: 두 브라우저에서 댓글과 보드 댓글 수가 새로고침 없이 일치한다.

## 6. 통합 검증과 전달
- [ ] 사진 등록과 그림 등록을 각각 검증한다.
- [ ] 다른 브라우저에서 새 카드·새 댓글·댓글 수 동기화를 확인한다.
- [ ] 최초 조회와 이벤트 경합, 재연결 누락 복구, 반복 모달 개폐 시 구독 정리를 확인한다.
- [ ] 업로드·DB·댓글 실패 시 입력 유지 및 재시도 중복 방지를 확인한다.
- [ ] 모바일 터치·카드 가독성·키보드 접근성을 확인한다.
- [ ] RLS·Storage 권한과 클라이언트 비밀키 미포함을 검증한다.
- [ ] 필요한 테스트, 코드 검사, 빌드를 실행하고 결과를 기록한다.
- [ ] README에 실행·환경변수·마이그레이션·익명 인증·Storage·Realtime 설정을 정리한다.
- [ ] 실제 결과에 맞게 Memory Bank 세 파일을 갱신한다.
- 완료 조건: 실행 가능한 앱과 설정 절차를 전달하고, 외부 설정 부족으로 검증하지 못한 항목은 명확히 남긴다.

## 범위와 의존성
- 데이터·권한 기반 이후 작성·보드·댓글 순서로 구현한다. 화면 골격은 외부 연결 없이 먼저 만들 수 있다.
- 실제 Supabase 연결이 없으면 통합·권한·실시간 검증을 완료로 표시하지 않는다.
- 공개 배포, 운영용 스팸 방지·신고·관리자 기능, 고아 파일 정리 자동화는 별도 후속 범위다.
