## 확인된 환경과 주의점
- 실제 GitHub 저장소 루트는 현재 작업 공간의 `supabasetest/` 하위 폴더다.
- 원격 주소: https://github.com/b213066-sketch/supabasetest.git
- 문서 작성 전 저장소는 커밋이 없는 `main` 브랜치였다.
- 상위 작업 공간에도 별도 `.git`이 있으며 원격 주소는 설정되어 있지 않았다. 이번 문서는 실제 GitHub 저장소 안에 작성한다.
- Supabase 연결 정보·설정 상태와 배포 환경은 아직 확인하지 않았다. 이것이 문서 작성이나 로컬 화면 골격 작업을 막지는 않는다.

## 검증 기록
- 파일 시스템과 Git 명령으로 저장소 경계, 원격 주소, 초기 파일 상태를 확인했다.
- 문서 변경이므로 앱 테스트는 실행 대상이 없다. 생성한 문서 4개의 목록·내용과 Git 상태를 점검했다. 커밋 전 스테이징된 diff의 공백 오류도 확인한다.
- 실제 업로드·DB 저장·RLS·실시간 통신은 아직 검증하지 않았다.
